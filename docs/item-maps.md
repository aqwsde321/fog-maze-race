# 아이템전 가이드

현재 아이템 규칙은 방 생성 시점이 아니라, 방 안 대기 화면에서 방장이 `경기`를 `일반전 / 아이템전`으로 바꿔서 선택합니다.

## 모드 선택

- `일반전`: 모든 맵을 그대로 쓰되, 아이템 박스가 생성되지 않습니다.
- `아이템전`: 모든 맵에서 아이템 박스가 생성될 수 있습니다.
- `방 모드(normal / bot_race)` 와는 별개입니다.
- `RESET_ROOM` 이후에도 선택한 `경기` 값은 유지됩니다.

## 현재 규칙

- 인벤토리는 `1칸`만 지원합니다.
- 아이템을 들고 있는 동안에는 다른 박스를 추가로 먹을 수 없습니다.
- 기본 생성 규칙은 `레이서 수 x 2`입니다.
- 관리자 맵 편집에서 맵별 생성 수 규칙을 바꿀 수 있습니다.
  - `참가자 수 배수`
  - `고정 개수`
- 랜덤 박스는 `mazeZone` 안의 실제 길 타일에서만 생성됩니다.
- `startZone`, `connector`, `goalZone`, `fakeGoalTiles`, 시작 진입부 일부, 골 주변 일부는 생성 제외 구간입니다.
- 현재 아이템 박스에서는 아래 5종이 랜덤으로 나옵니다.
  - `ice_trap`
  - `return_trap`
  - `flare`
  - `boost`
  - `scanner`
- 아이템 사용 키는 `Space`입니다.

## 얼음 함정

`ice_trap`을 사용하면 현재 칸에 얼음 함정을 설치합니다.

- 설치 직후 상태는 `arming`
- 설치한 플레이어가 그 칸을 벗어나면 `armed`
- 다른 레이서가 해당 칸에 들어오면 발동
- 발동한 플레이어는 `1500ms` 동안 얼어붙어 이동할 수 없습니다.
- 설치한 플레이어 본인은 자기 함정에 걸리지 않습니다.

## 복귀 함정

`return_trap`을 사용하면 현재 칸에 복귀 함정을 설치합니다.

- 설치 직후 상태는 `arming`
- 설치한 플레이어가 그 칸을 벗어나면 `armed`
- 다른 레이서가 해당 칸에 들어오면 발동
- 발동한 플레이어는 즉시 공용 시작 첫 슬롯으로 되돌아갑니다.
- 설치한 플레이어 본인은 자기 함정에 걸리지 않습니다.

## 플레어

`flare`를 사용하면 잠시 동안 시야가 넓어집니다.

- 지속 시간: `4000ms`
- 현재 시야 반경에 `+1`이 적용됩니다.
- 예: `3x3 -> 5x5`, `5x5 -> 7x7`

## 부스트

`boost`를 사용하면 잠시 동안 한 번의 입력으로 더 멀리 이동합니다.

- 지속 시간: `3000ms`
- 이동 입력 1회당 최대 `2칸`까지 전진합니다.
- 첫 칸은 지나가고 두 번째 칸이 막혀 있으면, 첫 칸까지만 이동합니다.
- 이동 중 아이템 박스 획득, 함정 발동, 골 도착 판정도 중간 칸마다 그대로 적용됩니다.

## 스캐너

`scanner`를 사용하면 진짜 골까지의 다음 방향 힌트를 잠시 보여줍니다.

- 지속 시간: `4000ms`
- 실제 게임 중 자기 캐릭터 근처에 현재 위치 기준 `목표 방향` 화살표가 표시됩니다.
- 탐험형 봇은 스캐너가 켜진 동안 goal 경로를 바로 추적합니다.

## UI 표시

- 대기 화면 방장 패널에서 `경기` 셀렉트로 `일반전 / 아이템전`을 바꿀 수 있습니다.
- `일반전`에서 `아이템전`으로 바꿔도 현재 미리보기 맵은 유지되고, 생성 규칙만 달라집니다.
- 플레이 중 아이템을 들고 있으면 좌측 상단 HUD에 현재 보유 아이템과 `Space 사용`이 표시됩니다.
- `flare`, `boost`, `scanner`, `빙결`은 활성 중일 때 각각 별도 상태 카드가 표시됩니다.
- 맵 위에는 랜덤 박스와 얼음 함정이 오버레이로 렌더됩니다.

## 봇 동작

- 탐험형/빠른 봇 모두 아이템 박스를 주울 수 있습니다.
- 봇은 `mazeZone` 안에 들어온 뒤 보유 아이템을 자동 사용합니다.
  - `ice_trap`: 현재 칸에 기존 함정이 없을 때 설치
  - `return_trap`: 현재 칸에 기존 함정이 없을 때 설치
  - `flare`: 즉시 사용
  - `boost`: 즉시 사용
  - `scanner`: 즉시 사용
- `scanner`가 켜진 탐험형 봇은 잠시 동안 goal 경로를 직접 추적합니다.

## 구현 메모

- 서버 authoritative 규칙입니다.
- 아이템 보유, 얼음 상태, 랜덤 박스, 함정 상태는 모두 스냅샷에 포함됩니다.
- 아이템 박스 생성 여부는 맵 플래그가 아니라 현재 방의 `gameMode === "item"` 여부로 결정합니다.
- 맵별 `featureFlags.itemBoxSpawn`은 생성 개수 규칙만 조정합니다.
- 현재 범위에는 `fog_bomb`, 인벤토리 다중 슬롯, 수동 스폰 포인트 편집은 포함하지 않습니다.
